# ChatGPT Edu: семинар для учителей гуманитарных направлений

Интерактивная презентация с учебными заданиями, иллюстрациями и аудио.

Откройте сайт GitHub Pages этого репозитория. Презентация загружается из сжатых частей seminar-*.bin; все части должны оставаться рядом с index.html. Нужен современный браузер и интернет для первоначальной загрузки.
